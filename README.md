# 🎭 Barranquilla Carnival Parade Optimization using Mixed-Integer Linear Programming

## Overview

This repository presents a **Mixed-Integer Linear Programming (MILP)** optimization model developed in collaboration with **Carnaval de Barranquilla S.A.S.** as part of an undergraduate research project in Industrial Engineering.

The project addresses a real operational problem during the Barranquilla Carnival, one of the largest cultural festivals in Latin America: **reducing spectator waiting time by minimizing the gaps between consecutive parade groups (comparsas)** while preserving safe operational distances.

Unlike traditional scheduling problems, the objective is **not** to eliminate all spacing between groups. Since each comparsa has different dimensions, walking speeds, choreography, and number of participants, the model seeks an optimal balance between parade flow, safety, and spectator experience.

---

# Project Background

During the Barranquilla Carnival, hundreds of parade groups move along a predefined route.

Because each group differs in:

- Number of participants
- Physical length
- Average walking speed
- Choreography dynamics

large empty spaces frequently appear between consecutive groups.

These gaps reduce the overall spectator experience because attendees spend several minutes without seeing any parade activity.

This project develops an optimization model capable of generating improved parade block assignments that reduce these waiting periods while respecting operational constraints.

---

# Real Data Collection

One of the main strengths of this project is the use of **real operational data**.

Instead of relying on simulated information, data were collected directly during the **2024 Barranquilla Carnival** through field observations conducted at multiple official parades.

The collected information included:

- Parade block lengths
- Average walking speeds
- Checkpoint crossing times
- Route distances
- Initial parade sequencing

These measurements were transformed into the optimization model parameters.

---

# Problem Formulation

The problem is formulated as a **Mixed-Integer Linear Programming (MILP)** model.

The model determines the optimal assignment of parade blocks while minimizing the maximum spacing perceived by spectators.

Decision variables include:

- Binary assignment variables
- Block positions over time
- Maximum route coverage
- Maximum allowable gap

The optimization considers:

- Assignment constraints
- Position constraints
- Distance constraints
- Time evolution
- Big-M logical constraints
- Maximum gap restrictions

---

# Objective

The optimization aims to:

- Improve parade flow
- Reduce spectator waiting time
- Minimize the maximum gap between consecutive parade blocks
- Maintain realistic operational distances
- Generate feasible parade assignments

# Results

The optimization model was evaluated under different operational scenarios comparing:

- **AS-IS:** Original parade organization provided by Carnaval de Barranquilla.
- **TO-BE:** Optimized assignment generated by the mathematical model.

The proposed optimization achieved:

- Reduced maximum spectator waiting times
- More homogeneous distribution of parade blocks
- Improved parade flow consistency
- Better alignment between parade duration and operational expectations

The optimized assignments demonstrated a significant reduction in large empty spaces while maintaining realistic operational conditions.
